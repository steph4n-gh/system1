# Project media

The project logo is [system1-logo.jpg](system1-logo.jpg).

Earlier promotional charts, architecture images and animation generators were
retired because their fixed speedups, quality scores, safety labels or simulated
metrics did not match the recorded evidence. Current architecture is maintained
as a diagram in the [implementation reference](../docs/architecture/technical_specification.md).
Measured results are in the [workload report](../benchmarks/quality/workloads/README.md).

New media should state its source run and scope. Simulated frames, scripted input
and model suggestions must be labeled; failed measurements must not be replaced
with invented latency, confidence or verification results.
